Loop · v0.2.0 · system design study · 02 May 2026

Operator UIs for an autonomous dev pipeline.

Loop is a single-machine scanner that drives issues through a label state-machine — needs-po → needs-dev → needs-review → needs-qa → qa-pass → done — dispatching agents (claude / codex / gemini / aider) into isolated worktrees. Six handlers, one reconciler, many repos. The human is the operator: they label, then watch.

Per the README, the project intentionally has no GUI — visibility lives in loop-monitor. This study explores what an operator-side live view could look like if Loop ever wanted one: minimal, glanceable, label-truthful, and honest about Loop's place as a bridge between trackers and ship. Four artboards, side-by-side. Drag to reorder, click ⤢ to focus.
